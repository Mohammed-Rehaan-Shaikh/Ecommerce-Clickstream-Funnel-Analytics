# E-commerce Clickstream Funnel Analytics

## Overview
This project analyses anonymised e-commerce clickstream data to understand user behaviour across the product-view, cart, and purchase journey.

## Business Question
Where do users drop off in the conversion funnel, and which product categories may need improvement?

## Dataset
[eCommerce Events History in Electronics Store](https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-electronics-store)

## Tools Used
- Python
- pandas
- matplotlib
- seaborn
- Jupyter Notebook

## Analysis Performed
- Data quality checks
- Missing-value handling and duplicate removal
- Session-level View → Cart → Purchase funnel
- Conversion-rate calculation
- Category-level conversion comparison
- Funnel visualisation
